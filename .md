### C. Standardized API Endpoints (Sanctum Protected)
All API endpoints follow a standardized JSON response: `{ "success": true/false, "message": "...", "data": [...] }`

- **Auth System**: OTP dispatch to Log/Mail, registration for new buyers, profile retrieval (`/api/auth/me`), and logout.
- **Listings Hub**: Filtering by price, category, grade, brand, and search matching title/description.
- **Buyer Desk**: Order creation, payment authorization simulation, escrow holding locking, delivery confirmation, raising dispute (`dispute_type` validation enums), and seller ratings.
- **Seller Desk**: Dashboard statistics (earnings, active counts), listings CRUD, order shipment confirmations (Shiprocket mock labels), and dispute response logs.
- **Asynchronous Webhooks**:
  - `/api/webhooks/razorpay`: Captures payments, flags listing as sold, sets order status to paid, creates held escrow.
  - `/api/webhooks/shiprocket`: Updates delivery statuses (picked_up, transit, delivered) and triggers testing window timers.

### D. Scheduled Cron Tasks & Queue Jobs (`routes/console.php` & `app/Jobs`)
- **`EscrowAutoReleaseJob`** (Hourly): Checks expired testing window timers, auto-completes orders, and releases escrow funds.
- **`DisputeEscalationJob`** (Hourly): Auto-escalates open disputes to admin review if the seller response deadline (48 hours) passes.
- **`AutoRatingJob`** (Daily 2:00 AM): Auto-seeds 5-star reviews for completed orders after 7 days if the buyer hasn't rated.
- **`SellerMetricsJob`** (Daily 3:00 AM): Recalculates dispute rates, star averages, cooperation score penalties, and updates metrics.
- **`BadgeCalculationJob`**: Triggered immediately after order completion to recalculate seller badge levels based on:
  - `basic`: Default level.
  - `verified`: `kyc_status = approved` AND `completed_orders >= 1`.
  - `fulfilled`: `completed_orders >= 10` AND `avg_response_time < 3` hours AND `cooperation_score >= 7` AND `star_rating >= 4.0` AND `shop_visit_verified = true`.
  - Side effects: Logs changes to `badge_logs` and emails the seller on badge change.
- **`BuyerBadgeJob`**: Recalculates buyer badges on users table silently after order completion:
  - `completed_orders < 5 = new_buyer`
  - `completed_orders >= 5, fraud_disputes = 0 = verified_buyer`
  - `completed_orders >= 10, fraud_disputes = 0 = trusted_buyer`
